# BMI Calculator — Persian Number-to-Words

A single-page BMI calculator with Persian (Farsi) number-to-words conversion.

## Features

- Calculate BMI from weight (kg) and height (cm)
- Display BMI in Persian digits (۰۱۲۳۴۵۶۷۸۹)
- BMI value written in Persian words
- BMI category in Persian (کم‌وزنی / نرمال / اضافه‌وزن / چاقی)
- RTL layout with Vazirmatn font
- Works offline (open index.html directly)

## Tech Stack

- Vanilla HTML/CSS/JS
- No frameworks, no build step
- Vazirmatn font from Google Fonts CDN

## Usage

Open `index.html` in a browser, enter weight and height, click "محاسبه".
